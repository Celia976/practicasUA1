# Prácticas de Empresa con 3D Soul School - Creación de Personajes para Unity

Este repositorio recoge las prácticas realizadas durante el mes de julio (Inicio: 01-07-2026 - Fin: 31-07-2026), centradas en el flujo completo de creación de un personaje 3D y su integración en **Unity**.

## Objetivos

El objetivo de las prácticas ha sido recorrer el pipeline habitual de producción de un personaje 3D, desde la generación del concepto inicial hasta su utilización dentro de un motor de videojuegos.

## Proceso de trabajo

El desarrollo del proyecto ha seguido las siguientes fases:

1. **Generación de imágenes de referencia** mediante inteligencia artificial.
2. **Conversión a modelo 3D** utilizando Tripo 3D.
3. **Esculpido** para mejorar la geometría y los detalles.
4. **Retopología** para optimizar la malla.
5. **Desplegado de UVs**.
6. **Bake de materiales y texturas**.
7. **Texture Painting** para el acabado final.
8. **Rigging** mediante **Rigify** en Blender.
9. **Animación** del personaje.
10. **Importación e integración** en Unity.

## Herramientas utilizadas

* Blender
* Tripo 3D
* Unity
* IA para generación de imágenes
